# Timeline UI

`TimelineView` preserves the timeline model contract and composes `TimelineToolbar`, `TimelineViewport` and `TimelineEditing`, with `TimelineKeyboard` routing shortcuts. The viewport virtualizes `TrackRow`; each row pairs `TrackHeader` and `TrackLane`. Lanes instantiate only visible `ClipItem`s, which use `WaveformPreview`. `Playhead` draws the transport and snap markers. `ZoomControls`, `ToolButton` and `ToggleButton` share focus, hover and tooltip styling.

Use PascalCase for component files, camelCase for properties, and explicit required inputs and request signals. Components never reach into a parent's IDs. Visual tokens live in the resource-backed `theme/Theme.qml` singleton: **no hard-coded values, everything from Theme**. Numeric model calculations and interaction logic are not visual tokens. Waveforms are deterministic placeholders. Bars:beats currently assumes 120 BPM and 4/4 because the model contract has no tempo or meter. Inline rename is deferred until the contract supports names.
